# Licensing and reuse
This registry is a metadata and discovery index by default. Public accessibility does not imply permission to copy or redistribute.

Record separate license assertions for book/text content, code, figures, datasets, notebooks, generated outputs, and third-party assets. A repository-level code license does not automatically cover manuscript content or bundled assets.

Statuses: `verified` (authoritative evidence inspected for scope), `reported` (stated but not fully checked), `conflicting`, `unknown`, `not_applicable`.

Store license name/version or SPDX ID, scope, evidence URL/path, date checked, reviewer, and notes. If scope is unclear, link to the original and do not redistribute. This repository's license applies only to original contributions it has authority to license.
